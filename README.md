# SpaceVision: Satellite Image Analysis and Change Detection

A Python-based Earth observation research project using Sentinel-2 satellite imagery to analyze vegetation and surface changes over time.

## Objectives

- Retrieve satellite imagery using Google Earth Engine.
- Visualize true-color and false-color composites.
- Calculate the Normalized Difference Vegetation Index (NDVI).
- Compare satellite observations from different dates.
- Produce maps, statistics, and research visualizations.

## Technologies

- Python
- Google Colab
- Google Earth Engine
- Sentinel-2 Level-2A
- NumPy and Pandas
- Matplotlib and geemap

## Project Status

Currently in the initial setup phase.
